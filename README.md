# Chocolatey-Personal
This is my script to install my personal programs that I use most of the time

You are free to frok it!

## List of programs ##
- Steam
- Edge
- Vlc
- 7zip
- Gimp
- Kdenlive
- HandBrake
- OBS
- Localsend
- qbittorrent
- vscode
- Foxitreader

  
## Script ##
```
choco install steam vlc 7zip gimp kdenlive handbrake obs-studio localsend qbittorrent vscode foxitreader -y
```
